# Millionaire Quiz Game

A simple Python quiz game inspired by the "Who Wants to Be a Millionaire?" format.

The player answers multiple-choice questions and tries to win the highest prize by giving correct answers.

## Features

- Multiple-choice questions
- Prize progression system

## How to Run

```bash
python main.py
```

## Concepts Used

- Python functions
- Lists and dictionaries
- Loops
- Conditional statements
- User input handling
